05

Perguntas frequentes

A conversa é confidencial?

Sim. A lista e os arquivos que você manda para avaliação não são repassados a ninguém além do comprador. Projeto que não for aceito não é usado. Como a licença permite publicação, mande só projetos que você pode liberar.

Quem compra os projetos?

Empresas de IA que treinam modelos de engenharia. Os projetos servem como dados de treinamento desses modelos.

Preciso mandar os arquivos para a avaliação?

Não. Para avaliar basta a lista com nome, tipo e software de cada projeto. Os arquivos só vão depois que a licença estiver assinada.

E se um arquivo for recusado?

Não há pagamento por ele e ele não é usado. Você não tem custo nenhum com a recusa.

Como é feito o pagamento?

Por Pix ou transferência bancária, depois que o comprador aprova o arquivo, contra nota fiscal ou recibo.
